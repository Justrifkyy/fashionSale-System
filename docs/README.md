# Dokumentasi Care Care

- spec/carecare-app-spec.json : sumber kebenaran utama (baca ini dulu)
- brand/ : logo dan panduan brand
- design/DESIGN.md : sumber kebenaran visual (baca sebelum membuat UI)
- design/ : wireframe dan mockup
- flows/ : diagram alur (status pesanan, checkout, reservasi stok)
- legal/ : draf kebijakan (arsip, versi tayang diedit lewat admin)
- decisions/ : catatan keputusan (satu file per keputusan)
- runbook/ : deploy, backup, penanganan insiden
